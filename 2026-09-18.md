## Fix status (2026-09-18, Claude)
Verified at iPhone size (402×874) in headless Chrome against the local backend, plus the iOS 27 simulator.

- [x] **Navbar messy (iOS 18.6 + 27).** Wordmark was clipped to "CourseFor" and sign-out was pushed off the right edge. On phones: tighter padding and gaps, "AI SYSTEMS" hidden, username pill icon-only (name kept in the tooltip). Desktop unchanged.
- [x] **Prompt page overlapping the Target Blueprint.** Root cause: the Parameters panel was `sticky` on phones too, so it stayed pinned while the roadmap scrolled over it (that's why "Beginner / Intermediate / Advanced" floated between week cards). On phones the roadmap is now its own screen; desktop keeps the sidebar.
- [x] **Where's the prompt box?** A "← New path · Your paths" link now sits at the top of the roadmap on phones.
- [ ] **Google sign-in blank screen.** Can't work with Google's web button inside an app: its popup opens outside the webview and has nothing to report back to. Native Google sign-in is built (`@capgo/capacitor-social-login`) and the app hides the button until it's configured. **Needs you:** create an iOS OAuth client in Google Cloud Console (bundle ID `ai.courseforgeapp.app`) and send me the client ID.
- [x] **First letter auto-capitalized.** Happens on real iPhones too. Username, email, password and invite-code fields now opt out. This also fixed a hidden bug: invite codes are lowercase, so a capitalized code **failed to join a group**. The backend now accepts any case.
- [x] **Ollama nearly crashed the Mac.** Quizzes were Ollama-first. Now Azure first, with qwen3.5:2b as the fallback. Two more fixes found while testing:
  - 2b loaded at 5.9 GB because it reserved its full 262K context; capped to 16K, it loads at 2.7 GB.
  - 2b returned the wrong number of questions 3 times in 5, and half its answer keys matched none of its own options. Now forced into the right shape: 5/5 quizzes, 15/15 gradeable.
  - The 2b content quality is only so-so, so it's a fallback, not a replacement.
- [x] (not on the list) **PDF download button** is hidden in the app, where it can't work. Markdown download stays.
